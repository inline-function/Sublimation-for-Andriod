# 安卓标准库

> 为了使得CandyIDE支持安卓端的开发，Sublimation需要提供一组专用于安卓平台的标准库。
>
> 本文档是根文档，AI未经允许不得修改，否则让你飞起来。

## 简介

Sublimation编译器将代码编译为JS代码，然后在安卓APK中通过webview运行。安卓APK中已经包含一些原生支持器代码，用于调控JS端和原生端的交互。

## 活动

安卓平台通过一个个的**活动**组织程序，在Sublimation中，应用仅由一个活动构成，因此只需要管理这一个活动的生命周期即可。

在主函数中，通过`android.activity`下的函数控制当活动触发生命周期事件时的行为。

```
fun main() {
    onCreate {
        log("it works!")
    }
}
```

活动主要有七个生命周期：

1. **onCreate()**  
   活动首次创建时调用。用于初始化操作，如设置布局、绑定数据、初始化变量等。整个生命周期中只调用一次。

2. **onStart()**  
   活动变为可见但尚未与用户交互时调用。此时活动已进入前台，但可能被其他活动部分遮挡。

3. **onResume()**  
   活动获得焦点、可与用户交互时调用。此时活动处于前台并处于运行状态，是用户实际操作的阶段。

4. **onPause()**  
   活动失去焦点但仍部分可见时调用（如弹出对话框、切换到另一个活动）。用于保存临时数据、暂停动画/视频等耗时操作，应快速执行。

5. **onStop()**  
   活动完全不可见时调用（如被新活动完全覆盖、用户按 Home 键）。用于释放资源、保存持久化数据等。

6. **onDestroy()**  
   活动被销毁前调用。可能是用户主动 finish() 或系统因内存不足回收。用于最终资源释放、注销监听器等。

7. **onRestart()**  
   活动从停止状态（onStop 之后）重新启动时调用，紧接着会调用 onStart()。用于恢复被暂停的状态。

编译成的APK只有一个活动，因此只需要管理这一个活动的生命周期即可。编译器会生成桥接，当这个活动发生了生命周期事件的时候，调用subl编译成的JS中相应的生命周期函数。

## 布局

布局采取声明式DSL构建应用的布局。布局是直觉主义的可变风格修改，但实际上会被编译器编译成不可变的状态流转。

```
fun main() {
    onStart {
        layout {
            Box(
                modifier = fillMaxSize(),
                contentAlignment = Center()
            ) {
                Button {
                    Text("居中按钮")
                }
            }
        }
    }
}
```

> 当结构体的最后一个参数是函数时，构造结构体可以进行尾随调用。

类似`Button``Box`这种结构体标注了`@view`，称它们为**视图结构体**，编译器对它们有特殊优化。视图结构体只能在标注有`@composable`的函数中构造。

视图结构体最后一个参数是`body`，编译后新增一个属性`chilren`，在`body`其中构造的子视图们会被编译成这个视图结构体`children`属性的成员，而`body`本身会被擦除。因此，`body`中应该只写视图结构体的构造，不要写逻辑代码。

视图结构体会被编译器加上一个属性`recomposition`，当视图被修改的时候，视图会调用这个属性，然后把修改好的视图传给他，而原来的视图依然不变。

编译为JS并且打包为APK后，编译器会根据JS端调用`layout`函数传来的视图结构体，进行动态的视图构建，然后设置为当前活动的布局。当视图被修改时调用的`recomposition`，实际上就是通知KT端视图发生更新：`recomposition`的参数会被原样替换进当前视图树。

### 视图定位：`__ord`

每个视图构造点会被编译器注入一个`__ord: Nat`属性（从1开始，按**源码出现序**为每个视图名分别编号），它与重组函数`recomposion$X$N`的`N`同源，作为节点的唯一身份一并序列化进JSON。KT端据此精确定位被修改的节点——注意源码序与视图树的DFS序不一定相同（例如一个先声明的视图变量被嵌套放在树的后段），不能按出现次序推断位置。

### 增量重组

重组（以及重复调用`layout`）不是整树重建：KT端会对新旧两棵JSON树做深比较（`jsonEquals`），**完全相等的子树原样保留**——其原生视图对象、状态与监听器都不重建；只有发生变化的子树才会在原位置被移除并重建。容器视图（`Box`）自身字段不变时还会继续向下逐子树增量。频繁修改少量小视图时，重建量≈变化量。

# 安卓API

安卓方面有独特的安卓API。

## log函数

`log`函数会把内容输出到应用自带的日志中，可以在adb以及shizuku中被外部应用获取，用于调试。它有两个参数，第一个参数是`Str`，表示日志内容；第二个参数是输出等级，默认值是`Info`。

## toast函数

`toast`函数会弹出一个提示，它有两个参数，第一个参数是`Str`，表示提示内容；第二个参数表示是否长时显示，默认值为`false`。

## Modifier 与 Alignment

`Modifier`与`Alignment`是**枚举**（不是字符串/整数），编译器在编译期就能挡住非法取值；KT端按枚举标签解析为原生布局参数。

- `Modifier`：`Plain()`、`FillMaxSize()`、`WrapContent()`、`Padding(n)`、`Width(n)`、`Height(n)`。构造函数：`fun fillMaxSize(): Modifier`、`wrapContent()`、`padding(n)`、`width(n)`、`height(n)`。
- `Alignment`：`Center()`、`TopStart()`、`BottomEnd()`、`CenterStart()`、`CenterEnd()`、`Top()`、`Bottom()`，作为视图结构体`contentAlignment`的取值。

> 由于函数支持**尾部默认参数**，调用`toast("hi")`、`log("hi")`时可省略带默认值的参数；视图结构体的`modifier`/`contentAlignment`也都有默认值（`Plain()`/`Center()`）。



## 基础视图（@view 结构体）

除 `Box`/`Button` 外，标准库新增以下视图结构体。它们只能在 `@composable` 函数（或 `layout` 块）中构造，构造规则与 `Button` 相同：最后一个参数若是函数型字段（如 `onClick`、`onChange`、`onToggle`），可以用尾随 lambda 形式书写，也可以用具名参数；编译器会把函数型字段编译成 `__dshFn_<视图>_<字段>_N` 桥键（`N` 为 `__ord`），KT 侧原生视图变更时通过该键回呼 JS 的 lambda。

| 视图 | 字段（均有默认值） | 说明 |
| --- | --- | --- |
| `Text` | `text`、`color`（`"#RRGGBB"`）、`size`（sp）、`bold`、`italic`、`maxLines` | 文本视图。`color`/`size` 等为可选修饰 |
| `TextField` | `placeholder`、`text`、`keyboard`（`"text"`/`"number"`）、`onChange: (Str) => Null`、`body` | 输入框。每次输入都同步触发 `onChange`，参数为当前完整文本 |
| `Switch` | `checked`、`enabled`、`onToggle: (Bool) => Null`、`body` | 开关 |
| `Checkbox` | `checked`、`text`、`onToggle: (Bool) => Null`、`body` | 复选框。`text` 是 `Str`，不是视图 |
| `Slider` | `value: Rat`、`from: Rat`、`to: Rat`、`onChange: (Rat) => Null`、`body` | 滑块，值会被钳制到 `[from, to]`；拖动过程中 `onChange` 连续触发 |
| `Image` | `name: Str`、`body` | 显示应用内图片资源；`"android:xxx"` 前缀使用系统内置图标 |
| `Progress` | `value: Nat`（0~100）、`indeterminate`、`body` | 进度条。`indeterminate=true` 为旋转等待圈 |
| `TimelineView` | `times: List[Str]`、`labels: List[Str]`、`orientation`（`"vertical"`/`"horizontal"`）、`color`（`"#RRGGBB"`）、`body` | 可滑动时间线：每个时间点一行（时间 + 标注），内容超出可视区域时滚动；`labels` 与 `times` 逐项对应，空列表只显示时间点 |

`Box` 支持 `orientation`（`"vertical"`/`"horizontal"`，默认纵向）与 `backgroundColor`（`"#RRGGBB"`）字段。

> 视图的 `body` 里通常用 @mut 变量持有子视图，在回调 lambda 里修改变量字段（如 `label.text = ...`），触发定向重组；不要在 `TextField.onchange` 里改 `TextField` 自身的字段——会重建输入框并丢焦点。把回显文本放在另一个 `Text` 里即可。

### 时间线视图：`TimelineView`

把服药/事件时刻渲染为可滑动的纵向列表（`orientation = "horizontal"` 时横向滑动）：每个时间点一行，左侧时间、右侧标注，以圆点/连线串联。`times` 为时间点文本（推荐 `nowStr()` 的 `"MM-dd HH:mm"` 格式），`labels` 为逐项标注（如 `"药名 · 剂量"`），与 `times` 一一对应；`labels` 为空时只显示时间点。

TimelineView 是**叶子数据视图**（与 `Chart` 同类）：数据以 `List[Str]` 字段传入、不带子视图；修改数据后重新构造并赋值给 @mut 变量即可触发定向重组（`recomposion$TimelineView$N`），整行替换。

**KT 端渲染协议**（工程整合侧在 `DshBridge.buildView` 增加 `"TimelineView"` 分支即可）：

| JSON 字段 | 类型 | 说明 |
| --- | --- | --- |
| `tag` | `"TimelineView"` | 节点标签 |
| `times` | 字符串数组 | 每行的时间点文本 |
| `labels` | 字符串数组 | 每行标注（长度可与 times 不同；空列表只显示时间） |
| `orientation` | `"vertical"` / `"horizontal"` | 滚动方向（默认纵向） |
| `color` | `"#RRGGBB"` | 时间线主色（空串 = 主题默认） |
| `modifier` | Modifier | 通用布局修饰（`setModifier`） |
| `__ord` | Nat | 节点身份，增量重组定位用（与其它视图一致） |

建议实现：`ScrollView`（横向时 `HorizontalScrollView`）内放 `LinearLayout`；每行一个横向 `LinearLayout`——时间 `TextView` + 圆点 `View`（`color` 为空时用主题色）+ 标注 `TextView`。

## 药品记录数据模型与持久化（meds.subl）

吃药 app 的数据层（`app/meds.subl`）：一条记录 = 药名 + 剂量 + 服药时间，编码为

    "name | amount | time"（如 "阿莫西林 | 1 片 | 10-25 15:20"）

多条以 `;` 拼接整体写入 storage 键 `"meds"`（与 language-service 的用药助手雏形同约定，见 `LspAnalysisTest` 内联源码）。记录列表为 `List[Str]`，新增条目以 `cons` 头插（最新在前）。

| 函数 | 签名 | 说明 |
| --- | --- | --- |
| `doseEntry` | `(name: Str, amount: Str, t: Str): Str` | 编码一条记录 |
| `makeDose` | `(cur: List[Str], name: Str, amount: Str, t: Str): List[Str]` | 头插一条记录，返回新列表 |
| `doseName`/`doseAmount`/`doseTime` | `(entry: Str): Str` | 取记录字段（按 `" | "` 切分，字段缺失返回 `""`） |
| `medTimes` | `(meds: List[Str]): List[Str]` | 全部服药时间点（供 `TimelineView.times`） |
| `medLabels` | `(meds: List[Str]): List[Str]` | 全部标注 `"药名 · 剂量"`（供 `TimelineView.labels`） |
| `joinMeds` | `(xs: List[Str]): Str` | 列表转存储串（`;` 分隔） |
| `loadMeds` ⚠ | `(): List[Str]` | 读取已保存的记录（空串视作无记录） |
| `saveMeds` ⚠ | `(xs: List[Str]): Null` | 覆盖保存（`storagePut("meds", ...)`） |
| `nowStr` ⚠ | `(): Str` | 当前时间格式化为 `"MM-dd HH:mm"`（`fmtTime(timeNow())`） |

⚠ = `@impure`：在纯作用域（`@composable` 的回调 lambda 等）调用需 `unchecked` 前缀；其余为纯函数。

用法示例（输入框 + 添加按钮 + 时间线 + 持久化）：

```subl
@composable
fun content(): Box {
    @mut var nameField = TextField(placeholder = "药名")
    @mut var amountField = TextField(placeholder = "剂量，如 1 片")
    @mut var meds: List[Str] = emptyList()
    @mut var curTime: Str = ""
    @mut var status = Text(text = "共 0 条")
    @mut var timeline = TimelineView()
    return Box(modifier = Plain()) {
        Box(modifier = Plain()) { nameField }
        Box(modifier = Plain()) { amountField }
        Box(modifier = Plain(), orientation = "horizontal") {
            Button(onClick = {
                unchecked curTime = nowStr()
                meds = makeDose(meds, nameField.text, amountField.text, curTime)
                unchecked saveMeds(meds)
                status.text = concat(concat("共 ", toStr(size(meds))), " 条")
                timeline = TimelineView(times = medTimes(meds), labels = medLabels(meds))
                nameField.text = ""
                amountField.text = ""
            }) {
                Text(text = "＋ 服药")
            }
        }
        Box(modifier = Plain()) { status }
        Box(modifier = Plain()) { timeline }
    }
}
```

冷启动恢复：`unchecked meds = loadMeds()`（如在 `onStart` 里读取后重建 `timeline`）。

## 意图（Intent）

`android.intent` 命名空间下的 @impure @android 函数，全部需要 `unchecked` 语句调用：

| 函数 | 行为 |
| --- | --- |
| `openUrl(url: Str)` | ACTION_VIEW 打开网页/协议 |
| `shareText(text: Str)` | ACTION_SEND + 系统分享面板 |
| `dial(phone: Str)` | ACTION_DIAL 拨号盘（不直接拨出） |
| `sms(phone: Str)` | 打开短信会话 |
| `openSettings()` | 跳到本应用详情设置页 |
| `launchApp(pkg: Str)` | 按包名启动第三方应用 |

示例：

```
Button(onClick = { unchecked shareText("你好") }) {
    Text(text = "分享")
}
```

## 平台能力

`android.platform` 命名空间下的函数同样是 `unchecked` 调用：

| 函数 | 说明 |
| --- | --- |
| `clipboardSet(text: Str)` / `clipboardGet(): Str` | 剪贴板读写 |
| `storagePut(key: Str, value: Str)` / `storageGet(key: Str): Str` | 轻量持久化（SharedPreferences `dsh-storage`），重启 APP 后仍在 |
| `keepScreenOn(on: Bool)` | 保持屏幕常亮 |
| `vibrate(ms: Nat)` | 振动，需 `VIBRATE` 权限（模板已内置） |
| `screenWidth(): Nat` / `screenHeight(): Nat` / `screenDensity(): Nat` | 屏幕宽度/高度/密度 |
| `installedApps(): List[Str]` | 已安装应用包名列表 |
| `pickFile(mime: Str, then: (Str) => Null)` | 命中取系统文件选择器，`then` 回调收的是文件路径 |

`pickFile` 是异步返回型：`then` lambda 由 KT 侧通过注册的桥键回呼（如 `Then(android:pickFile)`）。

## 返回值型安卓内建

`android` 命名空间中返回标量值的内建（`clipboardGet`、`storageGet`、`screenWidth` 等）在 JS 端被包装为返回解析值（Nat/Int/Bool 经 JSON.parse，List/Optional 经展开，Str 原样）；视图`...`事件类回调由 KT 主动发起，不走返回值通道。
